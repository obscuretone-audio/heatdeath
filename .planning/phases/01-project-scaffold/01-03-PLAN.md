| Boundary | Description |
|----------|-------------|
| DAW host → plugin | DAW calls processBlock with arbitrary buffer sizes and sample rates; plugin must not crash on odd layouts |
| build system → FetchContent network | CMake fetches JUCE from GitHub; MITM could inject malicious code |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | FetchContent JUCE clone | mitigate | Pin JUCE to specific tag `7.0.12` in CMakeLists.txt (Plan 01-01) — prevents arbitrary HEAD rolls |
| T-01-02 | Denial of Service | processBlock | accept | Phase 1 stubs are all pass-throughs; no DoS surface until Phase 2 introduces real DSP |
| T-01-03 | Information Disclosure | Plugin bundle metadata | accept | Bundle metadata is public-by-design (name, manufacturer); nothing sensitive in Phase 1 |
| T-01-04 | Elevation of Privilege | AU/VST3 loading in DAW | mitigate | auval in Task 2 enforces JUCE's standard sandbox-safe plugin contract; no custom code outside AudioProcessor boundary |
</threat_model>
